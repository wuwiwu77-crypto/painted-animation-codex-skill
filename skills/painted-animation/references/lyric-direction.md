# 歌词动画：对时、表演与画面排版

用于演绎歌词的 MV、歌词上屏，以及此类视频的修改。原则来自实际制作反馈；指南针、靠肩、手写字等是可选手法，不是每支视频的固定剧情。新请求优先于历史偏好。

## 1. 先固定真实音频时间，再安排分镜

- 保留用户指定的音源版本、截取起止与总时长。记录 `片段时间 = 原曲时间 - 截取起点`，不要混用两个坐标。不能为了整齐的分镜或节拍擅自移动截取范围。
- 优先使用对应这份音源的 LRC/时间戳，并检查它是否存在整体偏移或版本差异。只有句级时间时，不推断逐字高亮。
- 没有 LRC：先检查已有音频分析工具。可用本地转写结合已知歌词强制对齐，保留句首、句尾和关键动作对应词的时间与来源。伴奏、拖音、静音、重复歌词会造成错位；交叉检查，不把自动结果称为精确人工听校。节拍网格不能代替歌词定位。
- 无法可靠定位的句子先标为估计；不装作已验证。若缺失信息妨碍关键动作对时，再向用户索取相关句子的时间，不重复索要整套素材。需要新的大模型下载时，说明体积与用途并遵守下载约束；音频不因对时而自动上传第三方。
- 让字幕与场景、关键词动作读取同一个时间表，例如 `src/cues.js`。每行至少记：文本、开始、结束、关键词时点、证据/不确定性、对应画面事件。调整时间只改这一处；表情与转场相对该时间表派生。
- 歌词出现对应的画面含义：可以提前铺垫，但关键动作的落点要对应实际唱词。不要出现“日出”已唱完太阳才升起，或下一句开始却仍展示上一句核心动作的情况。
- 保持正常阅读顺序和停留时间；没有字级证据时采用短句显隐与已确认关键词强调。除非用户要 KTV 预读样式，不提前展示下一句。转场也不能延长上一句到错误的时间。

## 2. 从可辨识的物体到可理解的动作

- 为每个镜头写一句无需字幕也能看懂的描述，并明确“观众首先看见什么，随后理解什么”。抽象隐喻只有在镜头中建立含义后才使用。
- 物体看不清时，优先修正剪影、大小、材质线索和背景对比，不靠字幕解释。例如石块可有角面和裂缝，避免变成不明色团。
- 动词必须发生：日出要看到太阳越过地平线；方向怀疑可通过读得懂的指向物失常，再到角色的困惑反应。不要只换背景色或加没有因果的装饰线。
- 用户明确替换的意象、动作、结尾要记录为本项目约束。不能把已否定的飞行、红线等重新加入。并肩远去之类的结尾要保持落地、相对位置与连续缩小，再处理渐暗。

## 3. 情绪进展不能只是循环表情库

- 在分镜中并排比较相邻情绪段：眼形、嘴形、视线、身体倾斜、手势与动作幅度是否体现了变化。温柔、安心不能只重复前一段的惊讶或期待。
- 对情感转折设计专属关键姿势；需要时扩展眼形、嘴形与 `EMO`，而不是机械换预设名称。用户明确要求不重复时，检查实际画面是否不同，而非代码名字是否不同。不要反过来禁止所有合理的重复表情。
- 双人互动按因果展开：看见对方 → 一方靠近 → 另一方回应 → 接触后停留。两人的动作略有先后，不要同步镜像摇摆，也不要用同时闭眼代替真实依偎。
- 靠肩、拥抱、牵手等先检查接触姿势：肩/手实际相接，脸部仍可见，轮廓无穿插，脚接地；倾身不能让角色无意悬空。给观众足够时间读懂亲密感，呼吸起伏应小于接触动作。
- 心形、光晕等放在面部之外，不能挡眼睛和嘴；情绪演出优先于特效数量。表情切换仍须有眨眼/缓动等过渡，不瞬间跳脸。

## 4. 转场是两个镜头共同的动作

- 在每个镜头接缝记录离场、切换时点、入场和持续时间，包含开头与结尾。不能只在上一镜结尾闪一下，下一镜仍跳变。
- 优先让场景中的光、云、笔刷、形状或连续镜头推进承担过渡。适当变化手法，但不要为了“有转场”每次强闪或长时间铺满纯色。
- 遮盖式转场在切换点应完全遮住跳变，并在下一镜连续揭开；连续镜头则核对位置、大小、朝向、相机与色彩的两端值。圆形匹配只有位置、尺度与运动确实衔接才算匹配，不只是在两镜各画一个圆。
- 常见过渡可从约 0.4–0.7 秒试起，按音乐和内容调整，不固定为全片规则。过渡不能盖住关键词动作，也不能牺牲短句的阅读时间。
- 明确歌词的合成层次：随画面过渡还是保持在上层。无论选择哪种，歌词时间仍由音频表控制；结尾渐暗应覆盖文字，避免黑屏上突然残留字幕。

## 5. 字体和位置属于画面设计

- 手绘画面优先试与墨线、水彩相配的手写/毛笔字，而不是只将普通字幕放大。Ma Shan Zheng 是中文候选，不是固定指定字体；按可读性、情绪、字形覆盖和许可选用。
- 字体文件与许可证放在项目命名清楚的素材目录（如 `assets/fonts/`），无需系统安装。登记 `@font-face` 并通过 `window.EXTRA_FONTS` 等待加载；在最终渲染浏览器检查加载状态和代表性中文字符，防止静默回退或缺字。
- 每句在分镜中指定留白区域、字号层级、颜色与重点词。可用天空、侧边、人物上方及路径附近的空白，不默认所有句子固定在正下方。需要稳定字幕或用户明确指定时仍可统一底部。
- 一句可以自然断成两行，但要有清晰阅读路径，不能把字散到四角。避开角色脸、关键道具和事件；检查整个镜头中相机/人物移动后的遮挡，而非只检查一帧。
- 使用与画面协调的颜色、适度轮廓或局部淡墨保证对比；不自动套深色长条。关键词的大小、色彩或轻跳应服务语义，不能抢走角色表演。
- 字形可有稳定的轻微错落与纸纹，但不随机跳动；不要为长句逐字等待过长而错过演唱。字的进出与重点强调绑定共享时间表。

## 6. 修改与验收

先将用户反馈对应到受影响的镜头/时间、要保留的内容和可观察的通过条件。已经批准的方案直接实施；美术方向发生实质变化时才提交新的分镜审核。

完整渲染前检查：

- 每句开始附近、关键词时点和句末的实际画面：文字、动作和时间表一致；必要时回到音频证据复核。
- 每个情感转折的脸部特写、接触姿势及连续帧：表情不同、动作有回应、无穿插、不遮脸。
- 每处转场前中后的连续帧：无硬切泄漏，场景/歌词层次一致，关键事件未被遮没。
- 所有歌词版式的实际字体、缺字、对比度、安全边距与动态遮挡；全片淡出包含歌词。

保留已有交付视频，新版使用独立输出名。渲染缓存必须与修改版本对应，不能误复用旧字幕/旧表情的帧。最后解码完整 MP4，核对时长、分辨率、帧率、音轨；从成片抽查而不只看渲染前预览。格式检查通过不等于已证明听感或逐字同步，交付时如实区分。
